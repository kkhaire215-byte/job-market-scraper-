# Job Market Data Extractor 🚀

A lightweight Python automation tool that fetches real-time job listings via API and exports them directly into a clean CSV file.

## Features ✨
- **API Integration:** Connects seamlessly to live job endpoints.
- **Data Parsing:** Extracts Job Title, Company Name, Location, and Apply Link.
- **CSV Export:** Automatically saves structured data locally.

## Requirements 📦
- Python 3.x
- `requests` library

## How to Run 💻
```bash
pip install requests
python main.py
